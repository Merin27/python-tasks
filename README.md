# Python Learning Tasks 🐍

This repository contains a collection of Python practice tasks that I completed
while learning Python programming fundamentals.

The tasks focus on building strong problem-solving skills and understanding
core Python concepts through hands-on coding.

## Topics Covered
- Variables and Data Types
- Conditional Statements (if/else)
- Loops (for, while)
- Functions
- Lists, Tuples, Sets, Dictionaries
- String Manipulation
- File Handling
- Exception Handling
- Basic Object-Oriented Programming (OOP)
- Small logic-based programs

## Purpose of This Repository
- Practice Python fundamentals
- Improve logical thinking
- Build consistency in coding
- Track my learning progress
- Prepare for technical interviews

## How to Use
You can run any task file individually using:
python filename.py
